# 수문장 (sumunjang)

**AI에게 물어보기 전에, 개인정보는 문 앞에서 멈춘다.**

Claude Code나 ChatGPT에 로그·문서를 붙여넣는 순간, 주민등록번호·계좌번호·전화번호가
그대로 해외 API 서버로 전송됩니다. 수문장은 `base_url` 한 줄만 바꾸면 동작하는
**로컬 게이트웨이**로, 나가는 요청에서 한국 개인정보를 찾아 가명값으로 바꾸고
돌아온 답변에서는 원문으로 되돌립니다.

```bash
# 게이트웨이 실행
uvx sumunjang proxy --port 4000

# Claude Code가 수문장을 거쳐 나가게 한다
export ANTHROPIC_BASE_URL=http://localhost:4000
```

## 설계 원칙

- **탐지 코어에 서드파티 코드 없음** — 개인정보가 지나가는 경로(`detect`/`mask`)는
  Python 표준 라이브러리만 사용합니다. 공급망 공격 표면을 없애기 위한 의도적 선택입니다.
- **결정적** — 같은 입력이면 언제나 같은 출력. API 키도, 네트워크도 필요 없습니다.
- **조용히 실패하지 않음** — 마스킹을 보장할 수 없는 입력은 통과시키는 대신 경고하거나 차단합니다.
